# Fixtures

`<model>/<scenario>.jsonl`: one JSON object per line, `{ "t": <ms since the first line>, "event": <raw Anthropic stream event> }`, or `{ "t", "control": "disconnect" }`, or `{ "t", "throw": { status, type, message } }`. Generated by `pnpm fixtures` from `src/relay/scenarios.ts`; regenerate after changing a scenario.

`recorded/`: live streams captured with `RECORD=1` (git-ignored). Copy one over a generated file to replay a real response.
