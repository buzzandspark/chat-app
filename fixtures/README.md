# Fixtures

`<model>/<scenario>.jsonl`: one JSON object per line, `{ "t": <ms since stream start>, "event": <raw Anthropic stream event> }`, or `{ "t", "control": "disconnect" }`, or `{ "t", "throw": { status, type, message } }`; lines starting with `#` are ignored. Generated by `pnpm fixtures` from `src/relay/scenarios.ts`; regenerate after changing a scenario.

Scenarios run from memory. Replay mode reads only five files per model, `normal`, `long_reply`, `table_mid_stream`, `thinking_long` and `giant_code_block`, chosen by turn.

`recorded/`: live streams captured with `RECORD=1` (git-ignored). Copy one over a generated file to replay a real response.
